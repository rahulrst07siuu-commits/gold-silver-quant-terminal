## 3. GIT LFS (LARGE FILE STORAGE) RECOMMENDATIONS

If you prefer to keep repository clone sizes minimal for team members, Git LFS can be optionally enabled for `.joblib` binary artifacts:

```bash
# 1. Install Git LFS extension (one-time setup)
git lfs install

# 2. Track binary joblib models with LFS
git lfs track "*.joblib"

# 3. Add .gitattributes to git
git add .gitattributes
```

*Note: For a private repository with standard GitHub usage, committing the 6 model files directly (totalling ~120 MB) is also completely supported by GitHub since no single file exceeds the 100 MB hard ceiling.*
